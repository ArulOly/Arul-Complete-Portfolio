# Power BI Portfolio

This collection contains guide-based Power BI exercises covering local data processing, IT operations simulations, and reporting. Every project includes an AI-generated reference implementation, synthetic data, and recorded validation.

**Guides discovered** 1000

**Projects documented** 80

## Project categories

- Inventory
- Monitoring
- Audit
- Log Analysis
- Backup Verification
- Data Import
- Data Export
- Dashboard
- Alerting
- Scheduled Reporting
- Access Review
- Performance Baseline
- Service Check
- Configuration Comparison
- Error Handling
- Data Validation
- Documentation Generation
- Automation
- Visual Reporting
- Recovery Test

## Technologies covered

Power BI Desktop, Power Query M, typed tables, JSON, and table visuals.

## Using the embedded code

Use Power BI Desktop on Windows. Paste a project’s M code into the Advanced Editor of a blank query, load the output, and follow the table visual instructions.
