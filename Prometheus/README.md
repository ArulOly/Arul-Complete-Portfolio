# Prometheus Portfolio

This collection contains guide-based Prometheus exercises covering local data processing, IT operations simulations, and reporting. Every project includes source code, sample data, instructions to run it, and recorded validation results.

## Technologies covered

Prometheus recording rules, PromQL, and synthetic rule-test series.

## Using the embedded code

Save the source as `rules.yml`. Save the fixture below as `test.yml` in the same directory and run `promtool test rules test.yml`.
