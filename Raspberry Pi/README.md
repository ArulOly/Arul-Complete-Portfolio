# Raspberry Pi Portfolio

This collection contains guide-based Raspberry Pi exercises covering local data processing, IT operations simulations, and reporting. Every project includes source code, sample data, instructions to run it, and recorded validation results.

**Guides discovered** 1000

**Projects documented** 80

## Project categories

- Inventory
- Monitoring
- Audit
- Log Analysis
- Backup Verification
- Data Import
- Data Export
- Dashboard
- Alerting
- Scheduled Reporting
- Access Review
- Performance Baseline
- Service Check
- Configuration Comparison
- Error Handling
- Data Validation
- Documentation Generation
- Automation
- Visual Reporting
- Recovery Test

## Technologies covered

Bash, Raspberry Pi OS device-tree model metadata, and synthetic readings.

## Using the embedded code

Open a project, save its embedded source, and use the documented run command.
