This collection contains guide-based HTML CSS exercises covering local data processing, IT operations simulations, and reporting. Every project includes an AI-generated reference implementation, synthetic data, and recorded validation.

Semantic HTML, CSS Grid, responsive layouts, print styles, and native disclosure controls.

## Using the embedded code

Copy a project's HTML block to `index.html` and open it in a modern browser. CSS is included in the document.
