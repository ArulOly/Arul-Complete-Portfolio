## Technologies covered

JavaScript, Node.js standard-library modules, JSON and CSV processing, SHA-256, UTC dates, statistics, and command-line interfaces.

## Using the embedded code

Install Node.js 24 or later. Open a project, save its source as `project.mjs`, and create the sample input in a local practice directory. Follow the project's command and compare the result with its test observations.
