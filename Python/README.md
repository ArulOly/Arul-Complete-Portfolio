# Python Portfolio

This portfolio contains guide-based Python exercises for local data processing, IT operations simulations, automation, and reporting. Each project includes an AI-generated reference implementation, runnable synthetic data, and actual validation observations.

## Technologies covered

Python 3.10 or later and its standard library. The projects use JSON, CSV, Markdown, SHA-256 digests, date calculations, descriptive statistics, and command-line interfaces.

## Using the embedded code

1. Open a project below and copy its Python block into `project.py` in a local practice directory.
2. Save the project's sample data as described in its README.
3. Run the documented command from that directory. Follow any project-specific flags or input-file instructions.
4. Compare your run with the illustrative output and the recorded validation observations.
