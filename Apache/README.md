# Apache Portfolio

This collection contains guide-based Apache exercises covering local data processing, IT operations simulations, and reporting. Every project includes source code, sample data, instructions to run it, and recorded validation results.

**Guides discovered** 1000

**Projects documented** 140

- Inventory
- Monitoring
- Audit
- Log Analysis
- Backup Verification
- Data Import
- Data Export
- Dashboard
- Alerting

- Service Check
- Configuration Comparison
- Error Handling
- Data Validation
- Documentation Generation
- Automation
- Visual Reporting
- Recovery Test

## Technologies covered

Native Apache httpd configuration, static files, and a loopback HTTP endpoint.

## Using the embedded code

Open a project, save its embedded source, and use the documented run command.
