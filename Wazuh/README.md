# Wazuh Portfolio

This collection contains guide-based Wazuh exercises covering local data processing, IT operations simulations, and reporting. Every project includes source code, sample data, instructions to run it, and recorded validation results.

- Documentation Generation

- Visual Reporting
- Recovery Test

## Technologies covered

Wazuh local rule XML, JSON event fields, and synthetic controls.

## Using the embedded code

In a disposable Wazuh manager, store the XML as a local custom rule in the manager's rules directory and ensure the displayed rule ID is available. In `wazuh-logtest`, submit each event object as one JSON line and inspect the rule ID.
