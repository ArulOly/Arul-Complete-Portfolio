# Debian Portfolio

This collection contains guide-based Debian exercises covering local data processing, IT operations simulations, and reporting. Every project includes an AI-generated reference implementation, synthetic data, and recorded validation.

**Guides discovered** 1000

**Projects documented** 120

- Monitoring

- Data Import

- Dashboard

- Data Validation
- Documentation Generation
- Automation
- Visual Reporting
- Recovery Test

## Technologies covered

Debian, dpkg-query, Python, JSON, and local command-line reporting.

## Using the embedded code

Run the embedded Python on Debian. Save the project code and synthetic input locally and use the command in the README.
