# Greenbone Portfolio

This collection contains guide-based Greenbone exercises covering local data processing, IT operations simulations, and reporting. Every project includes source code, sample data, instructions to run it, and recorded validation results.

## Technologies covered

Simulated Greenbone GMP XML report data, XPath, and XSLT 1.0.

## Using the embedded code

Save the source as `report.xsl` and the fixture below as `report.xml`. Run `xsltproc --nonet report.xsl report.xml` to review the selected results.
