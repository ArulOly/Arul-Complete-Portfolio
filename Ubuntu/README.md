# Ubuntu Portfolio

This collection contains guide-based Ubuntu exercises covering local data processing, IT operations simulations, and reporting. Every project includes an AI-generated reference implementation, synthetic data, and recorded validation.

## Technologies covered

Ubuntu, dpkg-query, Python, JSON, and local command-line reporting.

## Using the embedded code

Run the embedded Python on Ubuntu. Save the project code and synthetic input locally and use the command in the README.
