# Grafana: Service Check — Recovery for Home Development (Project 043613)

## Project overview

A home development workspace provides the setting for this service check exercise. This project includes source code, sample data, and instructions to run it. The data is synthetic.

## Problem statement

The home development setting needs a repeatable way to review service check observations.

## Project objectives

- Visualize synthetic readings with the built-in TestData source.
- Demonstrate recovery with an explicit local sample.
- Reproduce the sample result and inspect how the project handles its documented edge case.

## Technologies used

Grafana dashboard JSON, TestData CSV Content, and dashboard field thresholds.
