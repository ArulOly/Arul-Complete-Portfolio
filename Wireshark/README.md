# Wireshark Portfolio

This collection contains guide-based Wireshark exercises covering local data processing, IT operations simulations, and reporting. Every project includes source code, sample data, instructions to run it, and recorded validation results.

**Guides discovered** 1000

**Projects documented** 400

- Inventory
- Monitoring
- Audit

- Data Import
- Data Export
- Dashboard
- Alerting

- Access Review

- Service Check

- Error Handling
- Data Validation
- Documentation Generation
- Automation
- Visual Reporting
- Recovery Test

## Technologies covered

Wireshark display filters, TShark, text2pcap, and synthetic UDP capture fixtures.

## Using the embedded code

Save the source as `practice.sh` and run `sh practice.sh`. The script generates the temporary capture from embedded text and prints the selected frame numbers.
