# Kubernetes Portfolio

This collection contains guide-based Kubernetes exercises covering local data processing, IT operations simulations, and reporting. Every project includes source code, sample data, instructions to run it, and recorded validation results.

**Guides discovered** 1000

**Projects documented** 180

## Project categories

- Inventory
- Monitoring
- Audit
- Log Analysis
- Backup Verification
- Data Import
- Data Export
- Dashboard
- Alerting
- Scheduled Reporting
- Access Review

- Service Check
- Configuration Comparison
- Error Handling
- Data Validation
- Documentation Generation
- Automation
- Visual Reporting
- Recovery Test

## Technologies covered

Kubernetes ConfigMap, Job, and Pod resource limits.

## Using the embedded code

Copy an embedded Job manifest to a local practice directory and follow the project command.
