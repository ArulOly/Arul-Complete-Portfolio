# Arduino Portfolio

This collection contains guide-based Arduino exercises covering local data processing, IT operations simulations, and reporting. Every project includes source code, sample data, instructions to run it, and recorded validation results.

## Technologies covered

An Arduino-compatible C++ sketch and Serial Monitor at 9600 baud.

## Using the embedded code

Open a project, save its embedded source, and use the documented run command.
