# Docker Portfolio

This collection contains guide-based Docker exercises covering local data processing, IT operations simulations, and reporting. Every project includes source code, sample data, instructions to run it, and recorded validation results.

**Guides discovered** 1000

**Projects documented** 100

## Project categories

- Monitoring
- Audit
- Log Analysis
- Backup Verification
- Data Import
- Data Export
- Dashboard
- Alerting
- Scheduled Reporting
- Access Review

- Service Check
- Configuration Comparison
- Error Handling
- Data Validation
- Documentation Generation
- Automation
- Visual Reporting
- Recovery Test

## Technologies covered

Docker CLI and POSIX shell with BusyBox awk.

## Using the embedded code

Copy an embedded container command to a local practice directory and follow the project command.
