This collection contains guide-based Redis exercises covering local data processing, IT operations simulations, and reporting. Every project includes an AI-generated reference implementation, synthetic data, and recorded validation.

## Technologies covered

Redis hashes, multi-command transactions, and expiration, Python, and structured JSON fixtures.

## Using the embedded code

Save the embedded Python code as `project.py` and the JSON sample as `sample.json`. Follow the project's database setup and run command.
