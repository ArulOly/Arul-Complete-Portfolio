# Ansible Portfolio

This collection contains guide-based Ansible exercises covering local data processing, IT operations simulations, and reporting. Every project includes source code, sample data, instructions to run it, and recorded validation results.

**Projects documented** 40

## Technologies covered

Ansible YAML, assertions, and Jinja filters.

## Using the embedded code

Copy an embedded playbook to a local practice directory and follow the project command.
