# Google Cloud Portfolio

This collection contains guide-based Google Cloud exercises covering local data processing, IT operations simulations, and reporting. Every project includes an AI-generated reference implementation, synthetic data, and recorded validation.

## Technologies covered

Google Cloud Storage event format, Python, JSON, and offline fixture-based testing.

## Using the embedded code

Save the embedded Python block and JSON sample, then run the documented command locally. The provider event and object storage are simulated.
